# Getting started

Devspace is a workspace for developers. It keeps your projects, tasks, notes, files, credentials and git history in one place, and starts your own IDE and terminal. It does not replace your IDE: it is the layer around it.

Everything is local. There is no account and nothing needs the network. Remote git actions and the optional GitHub integration are the only parts that use it, and the app works fully without them. Your notes and attachments are plain files, so the data stays portable.

## The window

- **Title bar.** The brand on the left, a search field in the middle that opens the [command palette](topic:search), and three small round window controls on the right (minimise, maximise, close).
- **Sidebar.** Your projects at the top. Under **Workspace**: Git, Run commands, Timesheet, Credentials, Settings and Documentation (this guide).
- **Canvas.** The page you are on: a project, a task, a note or one of the Workspace views.
- **Terminal.** A panel on the right with tabs, one set per project. Show or hide it with `` Ctrl+` ``. See [Terminal and run commands](topic:terminal).

## First steps

1. **Create a project.** Press the plus beside **Projects** (or `Ctrl+Shift+N`), type a name and press Enter.
2. **Link a git repository.** On the project page, link one or more repositories in the side rail. See [Projects](topic:projects).
3. **Add tasks.** Use **New task** on the project page. Tasks can have subtasks at any depth. See [Tasks and subtasks](topic:tasks).
4. **Write notes.** Add a note to the project, or write a task's description. Notes are Markdown. See [Notes](topic:notes).
5. **Open your editor.** **Open in IDE** on the project page starts the IDE you chose in [Settings](topic:settings).

## Finding your way

- `F1` opens this guide from anywhere.
- `Ctrl+K` (or `Ctrl+Shift+P`) opens the command palette. It finds commands, projects, tasks, notes and commits.
- Every shortcut is listed in [Search, palette and shortcuts](topic:search).

## Look and feel

The app is dark by default. In [Settings](topic:settings) you can switch to light or follow the system, make surfaces opaque (reduced transparency) and turn the animations off (reduced motion).
